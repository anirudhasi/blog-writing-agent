# Blog Writing Agent (LangGraph)

A LangGraph agent that turns a topic into a full Markdown blog post, with optional web research and generated diagrams.

```
router ─(needs research?)→ research (Tavily) → orchestrator (plan) ⇉ workers (one per section, parallel) → reducer
                                                                                  merge → decide images → generate (Gemini)
```

- **Router** picks `closed_book` / `hybrid` / `open_book` mode and writes search queries.
- **Research** searches with Tavily and keeps clean, recent evidence.
- **Orchestrator** writes a structured plan of 5–9 sections.
- **Workers** write sections in parallel via `Send`, citing evidence URLs.
- **Reducer** merges sections, plans up to 3 diagrams, and generates them with Gemini.

## Notebooks

| Notebook | Adds |
|---|---|
| `1_bwa_basic.ipynb` | Orchestrator → workers → reducer |
| `2_bwa_improved_prompting.ipynb` | Richer plans and prompts |
| `3_bwa_research.ipynb` | Router + Tavily research |
| `4_bwa_research_fine_tuned.ipynb` | Modes, recency filtering, citation rules |
| `5_bwa_image.ipynb` | Image-generation reducer subgraph |

## Run the app

```bash
pip install streamlit langgraph langchain-openai langchain-community python-dotenv pandas google-genai
cp .env.example .env   # fill in OPENAI_API_KEY, TAVILY_API_KEY, GOOGLE_API_KEY
streamlit run bwa_frontend.py
```

The `.md` files in the repo root are sample blogs generated by the agent.
